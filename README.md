# Kids Math Trainer

A simple Python math trainer for children in grades 1-5. Helps practice addition, subtraction, and multiplication in a fun and friendly way.

# Features

- Random math problems: `+`, `-`, `*`, ':'
- User chooses how many problems to solve
- 3 attempts per problem with hints
- Friendly messages that encourage children
- Error handling (program never crashes on wrong input)
- Final statistics and motivation
